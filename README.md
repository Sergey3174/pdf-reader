# Просмотр PDF

Одна страница для локальных PDF: выбор файла, перетаскивание, просмотр всех страниц в прокручиваемой ленте и масштабирование. Файлы не отправляются на сервер. PDF с паролем не поддерживаются.

Запуск: npm install, затем npm run dev.
Сборка: npm run build (результат в build).
Проверка кода: npm run lint.

React, TypeScript, Vite и PDF.js. Серверная часть не требуется.
